# 終電寝過ごし「詰み度」動画ジェネレーター

駅ごとの設定ファイル(JSON)から、点数・原稿・字幕つき動画(MP4、1920×1080)を作ります。

## ブラウザで使う(Renderにデプロイ)

駅レース動画と同じく、GitHubのリポジトリをRenderのDocker環境で動かすと、ブラウザから動画を作れます。

1. このフォルダの中身をGitHubのリポジトリにpushする
2. Renderで New → Web Service を選び、そのリポジトリを指定する(Runtime は Docker。`Dockerfile` を自動で使います)
3. デプロイ後のURLを開き、原稿ツールの「設定をコピー」で得たJSONを貼り付けて「動画を生成」を押す
4. 終わると、動画(MP4)、原稿、字幕、出典をダウンロードできます

- 「確認用(10コマ/秒)」は本番の3分の1ほどの時間で終わります。先にこちらで中身を確かめるのがおすすめです
- 生成物はサーバーの `output/` に置かれ、再デプロイや再起動で消えます。完成したらすぐダウンロードしてください
- 動画の生成はブラウザ(Chromium)を裏で動かすので、メモリとCPUを使います。無料プランのような小さい環境では、時間がかかるか、メモリ不足で止まる可能性があります
- ナレーションの合成(VOICEVOX)と収録音声の取り込みは、このWebページからは使えません。自分のPCで `render.py` を実行してください

自分のPCで同じページを動かすときは `python3 web/app.py` を実行し、`http://127.0.0.1:8080` を開きます。

## 準備(自分のPCで動かす場合、初回だけ)

```
pip install playwright
playwright install chromium
```

あわせて ffmpeg をインストールし、コマンドとして使える状態にしてください。

## 使い方

```
python render.py stations/otsuki.json              # 1駅
python render.py stations/*.json                   # まとめて
python render.py stations/otsuki.json --no-video   # 原稿と確認用HTMLだけ(数秒)
```

### ナレーションを入れる

動画の尺を声の長さに合わせます。1文ごとの音声の長さを測り、その長さで字幕と画面の進行を組み直してから、音声入りのMP4を書き出します。

```
python render.py stations/otsuki.json --voicevox 3          # VOICEVOXで合成(話者IDを指定)
python render.py stations/otsuki.json --voicevox 3 --voice-speed 1.15
python render.py stations/otsuki.json --voice-dir rec/      # 自分で収録した音声を使う
python render.py stations/otsuki.json --audio narration.wav # 1本の音声を重ねるだけ(尺は合わせない)
```

- `--voicevox`: PCで VOICEVOX を起動した状態で実行します。合成した音声は `out/駅名_voice/` に保存され、文が変わらなければ次回は使い回します。話者IDは VOICEVOX の `http://127.0.0.1:50021/speakers` で確認できます。公開時は VOICEVOX と各キャラクターの利用規約(クレジット表記など)に従ってください。
- `--voice-dir`: `out/駅名_lines.txt` に文の番号と本文が出ます。`001.wav`、`002.wav` … と番号どおりのファイル名で1文ずつ収録し、フォルダに入れて指定します(mp3、m4a も可)。
- どちらも、つなげた音声を `out/駅名_narration.wav` に書き出します。

`out/` に次のファイルができます。

| ファイル | 内容 |
|---|---|
| `駅名.mp4` | 動画 |
| `駅名.txt` | ナレーション原稿(読み上げる文だけ。見出しなし) |
| `駅名_sources.txt` | 出典表記(画面・概要欄用) |
| `駅名.srt` | 字幕の表示タイミング(ナレーション収録や編集の目安) |
| `駅名.html` | ブラウザで開ける確認用アニメ。再生・シークできます |

動画の生成は1駅あたり5〜10分ほどかかります。先に `--no-video` で点数と原稿、HTMLを確認するのがおすすめです。

## 駅を追加する

`stations/otsuki.json` をコピーして書き換えます。

| キー | 内容 |
|---|---|
| `station` `kana` `pref` `city` `line` `origin` `km` | 駅名、読み、都道府県、市区町村、路線、始発駅、始発駅からの距離 |
| `pref_code` | 地図で強調する都道府県のコード(01 北海道 〜 47 沖縄。山梨は 19) |
| `dep` `arr` `first` | 始発駅の発車時刻、終電の到着時刻、上り始発の発車時刻 |
| `taxi` | 途中駅までのタクシー料金。何駅でも可 |
| `taxi_to` | 採点に使う「○○駅までのタクシー代」の駅名、距離、料金。始発駅でなくてもよい |
| `hotel` `netcafe` `bath` | 駅から500m以内のビジネスホテル、ネットカフェ、深夜営業の入浴施設の数 |
| `○○_name` | 代表の店名(任意)。`hotel_name`、`conveni_name` など。2軒以上なら「○○など3軒」、1軒なら「○○の1軒」、0軒なら「なし」、5軒以上は数を出さず「5軒以上」と読み上げ・表示します |
| `karaoke` `famires` | カラオケ、24時間ファミレスの数 |
| `conveni` `conveni_walk_min` | 24時間コンビニの数、最寄り店までの徒歩分数 |
| `temp_jan` `temp_aug` `temp_station` | 1月と8月の平均最低気温、観測地点名 |
| `town_feature` `winter_comment` `summer_comment` `taxi_comment` `review` | 駅ごとに変わる文言 |
| `sources` | 出典表記 |
| `route` | 地図でなぞるルート。下の「ルートの指定」を参照 |
| `chars_per_sec` | 読み上げ速度(省略時 6.2 文字/秒)。大きくすると動画が短くなります |

点数、判定、原稿、地図の表示範囲は自動で決まります。

原稿ツール(ブラウザ)の「動画用の設定(JSON)」をコピーして、`stations/駅名.json` として保存する方法が手軽です。

### ルートの指定

駅レースビルダーと同じく、区間ごとに「路線・始点駅・終点駅」を並べます。線形は `rail.json`(関東と関西・東海の路線図データ)から取り出し、背景にも同じ路線網を薄く描きます。

```json
"route": {
  "region": "kanto",
  "segments": [
    {"line": "中央線快速", "from": "東京", "to": "立川"},
    {"line": "中央線快速", "from": "立川", "to": "高尾"}
  ],
  "extra": [["相模湖", 35.6165, 139.1885], ["大月", 35.6131, 138.9423, true]]
}
```

- `region`: `kanto`(関東)か `kansai`(関西・東海)
- `segments`: 路線名と駅名は `rail.json` にある名前で書きます。区間の始点と終点の駅名が地図に出て、途中の駅は小さな点になります
- `extra`: 路線データにない駅を、緯度と経度で直接指定します。区間の後ろに直線でつなぎます。4つ目を `true` にすると駅名が出ます
- 以前の形式(駅を `[駅名, 緯度, 経度, true]` で並べたリスト)もそのまま使えます

## 採点基準

| 項目 | 重み | 1点 | 2点 | 3点 | 4点 | 5点 |
|---|---|---|---|---|---|---|
| 始発までの待ち時間 | ×5 | 4時間未満 | 4:00〜4:20 | 4:20〜4:40 | 4:40〜5:00 | 5時間以上 |
| ○○駅までのタクシー代 | ×4 | 5千円未満 | 5千〜1万円 | 1〜2万円 | 2〜3万円 | 3万円以上 |
| 泊まれる場所 | ×4 | 4軒以上 | 3軒 | 2軒 | 1軒 | 0軒 |
| 時間を潰せる場所 | ×2 | 4軒以上 | 3軒 | 2軒 | 1軒 | 0軒 |
| 24時間コンビニ | ×2 | 4店以上 | 3店 | 2店 | 1店 | 0店 |
| 冬の最低気温 | ×3 | 2℃以上 | 0〜2℃ | -2〜0℃ | -4〜-2℃ | -4℃未満 |

判定: 50点未満「辛くない」、60点未満「耐え」、70点未満「気合いと根性」、80点未満「キツい」、80点以上「詰み」。

基準を変えるときは `render.py` の `score_*` と `verdict`、動画内の表は `template.html` の `RULES` を直します。

## ファイル構成

- `render.py` 採点、原稿の生成、動画の書き出し
- `web/app.py` ブラウザから生成するためのWebページ
- `Dockerfile` Render用の実行環境(ffmpeg、日本語フォント、Chromium入り)
- `template.html` アニメーション本体。演出を変えるときはここを編集
- `pref.json` 都道府県の境界データ(全国)
- `rail.json` 路線の線形と駅のデータ(関東84路線、関西・東海67路線。駅レース動画のリポジトリのデータから変換)
- `stations/` 駅ごとの設定

## 注意

- 県境データは国土地理院「地球地図日本」を簡略化したものです。動画で使うときは出典を表記してください。
- 関東の「中央線快速」は高尾までです。大月のように路線データの外にある駅は `extra` で補います。
- 湘南新宿ライン、上野東京ラインのように複数の系統が合流する路線は、区間によって遠回りの線形になることがあります。確認用HTMLで見て、おかしければ区間を細かく分けてください。
- 文字は Google Fonts を読み込みます。オフラインだとPCの標準フォントで描かれます。
- VOICEVOX連携は、エンジンに接続しての動作確認ができていません。うまく動かない場合はエラーメッセージを確認してください。
